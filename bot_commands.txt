start - Starts the bot
copy - Copies files from one channel to another (admin)
index - Indexes files from a channel (admin)
del - Deletes a file or a range of files (admin)
restart - Restarts the bot (admin)
restore - Restores TMDB photos (admin)
add - Adds a channel to the allowed list (admin)
rm - Removes a channel from the allowed list (admin)
broadcast - Broadcasts a message to all users (admin)
log - Sends the bot's log file (admin)
stats - Shows bot statistics (admin)
tmdb - Fetches TMDB information for a link (admin)
op - Performs an operation on a chat (admin)
block - Blocks a user (admin)
unblock - Unblocks a user (admin)
